# Initial Design Specification - AI Doc Downloader

Objective: Build a documentation downloader that takes a URL input and outputs a structured set of Markdown files.
Key Requirements:
- Use Playwright to handle Single Page Applications (SPAs) and dynamic rendering.
- Recursively crawl all pages under the same domain/subfolder scope using a queue.
- Built with TypeScript, Node.js, and Playwright.

---

## Step-by-step Design Plan

### 1. Project Setup
- Initialize Node.js project (`npm init -y`)
- Install core dependencies: `playwright`, `turndown` (HTML to Markdown)
- Install development dependencies: `@types/node`, `typescript`, `@types/turndown`
- Configure TypeScript (`tsconfig.json`) targeting `./dist`

### 2. Core Architecture
- **Crawler Engine**: Browser manager, BFS queue, visited URL filter.
- **HTML Processor**: Content cleaning, Turndown converter rules, heading normalization.
- **Output Storage**: Hierarchical Markdown storage matching URL paths with SQLite metadata tracking.

### 3. Core Capabilities
- Playwright browser automation for SPA routing.
- URL discovery via `<a>` tags with scope filtering (subfolder vs website).
- Content conversion pipeline converting HTML to fenced code block Markdown.

### 4. Advanced Enhancements
- Multi-worker concurrency control (`-c N`).
- Resume capability skipping existing pages recorded in `./docs.db`.
- Batch processing of pending URLs (`data/pending.yaml`).
- Automatic GitHub documentation & list downloader (`github_docs`).
- Remote environment support (`HOST_ENV=remote` -> `/srv/knowledge/`).
